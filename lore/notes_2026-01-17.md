### 1. Level 14 GARCH Bug Fix

**Problem**: L14 volatility_clustering was producing insane numbers:
- Prediction loss: 93.0 (should be ~1-2)
- Market returns: +407%, +754%, +2022%
- Alpha: -500% to -1700%

**Root Cause**: GARCH parameters were wrong:
```python
# BEFORE (buggy)
ALPHA = 0.05  # This was used as omega (constant term) - way too high!
BETA = 0.85
GAMMA = 0.10
variances[t] = ALPHA + BETA * variances[t-1] + GAMMA * prev_return**2
```

With ALPHA=0.05 as base variance, volatility was ~22% PER STEP (not per day).

**Fix** (`mcts_trader/data/synthetic_market.py`):
```python
# AFTER (correct GARCH(1,1))
OMEGA = 0.000001  # Base variance (tiny!)
ALPHA = 0.10      # ARCH coefficient (reaction to shocks)
BETA = 0.85       # GARCH coefficient (persistence)
variances[t] = OMEGA + ALPHA * prev_return**2 + BETA * variances[t-1]
variances[t] = np.clip(variances[t], 0.000001, 0.001)  # Cap at ~3% vol/step
```
