## Skeleton Module (`diff_teacher/skeleton/`)

### types.py
```python
@dataclass
class MarketSkeleton:
    trend_direction: Optional[Array] = None  # {-1, 0, +1} per timestep/asset
    vol_regime: Optional[Array] = None       # [0, 1] volatility percentile
    correlation_clusters: Optional[Array] = None  # Cluster IDs per asset
    alpha_shape: Optional[Array] = None      # Cumulative opportunity shape
    regime_sequence: Optional[Array] = None  # Regime indices over time
    events: List[Event] = field(default_factory=list)
    n_timesteps: int = 1440
    n_assets: int = 64
```

5 regime types: crash, rally, sideways, volatile, calm

### extraction.py
- `extract_skeleton()` - Full extraction from price data
- `extract_trend_direction()` - Sign of rolling mean returns
- `extract_vol_regime()` - Normalized rolling volatility
- `extract_correlation_clusters()` - Spectral clustering on correlation matrix
- `detect_regime_sequence()` - HMM-style regime detection

### encoder.py
- `SkeletonEncoder` - Encodes skeleton to FiLM parameters (gamma, beta, h0)
- Component encoders: TrendEncoder, VolRegimeEncoder, ClusterEncoder, AlphaShapeEncoder
- `SkeletonConditioner` - Combines timestep + skeleton conditioning
- Sinusoidal time embedding integrated

### builder.py
Fluent builder pattern:
```python
skeleton = SkeletonBuilder() \
    .add_regime('crash', duration=50) \
    .add_regime('recovery', duration=100) \
    .set_volatility_percentile(0.8) \
    .set_correlation_mode('crisis') \
    .build()
```

### ssm.py
- `selective_scan_sequential()` - Reference O(L) implementation
- `selective_scan_parallel()` - O(log L) using `jax.lax.associative_scan`

Key insight: The recurrence `h_t = A_t h_{t-1} + B_t x_t` is associative!

## Research: Time Series Foundation Models

Reviewed Chronos (Amazon) and MOIRAI (Salesforce) for ideas applicable to Poppy's prediction head.

### Chronos Key Ideas
- **Tokenization**: Quantize continuous prices into discrete bins (4096 vocab)
- **Mean scaling**: Normalize by absolute mean before tokenizing
- **Chronos-Bolt patches**: Chunk history into patches, direct multi-step (250x faster)

### MOIRAI Key Ideas
- **Any-Variate Attention**: Flatten 64 assets → single sequence with variate encoding
- **Multi-patch sizes**: Different patch lengths for different frequencies
- **Student-t mixture output**: Native fat tail modeling (better than Gaussian)
- **Modern tricks**: RoPE embeddings, SwiGLU activation, RMSNorm

### Quick Wins for Poppy
1. **Student-t output** - fat tails without symlog hacks
2. **Variate encoding** - for multi-asset attention
3. **RoPE embeddings** - relative position encoding upgrade

### Key Bug Categories Fixed

**Numerical Stability (div/0, overflow)**:
- Time embedding div/0: `jnp.maximum(half_dim - 1, 1)`
- KL divergence: `np.clip(ratio, 1e-10, 1e10)`
- Hill estimator: Guard zero sum
- Vol regime normalization: `jnp.maximum(max - min, 1e-10)`
- SSM exponential: `jnp.clip(..., -20.0, 20.0)`
- Skewness/kurtosis: `std > 1e-10` threshold

**State Management**:
- RNG mutation: Use `fold_in(base_rng, step)` pattern
- Unbounded lists: `deque(maxlen=N)` for metrics history

**Training Correctness**:
- PopArt: Filter valid samples before stats update
- Prediction loss: Apply valid_mask to decoder losses
- OHLCV indices: Created constants.py, fixed index 0→3 (Close)

**Memory/Performance**:
- d_state default: 64→16 to prevent OOM
- Causal conv: `mode='edge'` instead of `mode='constant'`
- Depthwise conv: `feature_group_count=self.features`

**Architecture Fixes**:
- Regime index OOB: `jnp.clip(regime_seq, 0, n-1)`
- JAX len() in traced: Use `.shape[0]`
- n_timesteps off-by-one: Store original before diff
- beta_s unused: Include in skeleton conditioning
- AdaLN-Zero: `sigmoid(gate - 5.0)` for near-zero init
- BiMamba: Flip conditioning for backward pass
