## Research: Time Series Foundation Models

Reviewed Chronos (Amazon) and MOIRAI (Salesforce) for ideas applicable to Poppy's prediction head.

### Chronos Key Ideas
- **Tokenization**: Quantize continuous prices into discrete bins (4096 vocab)
- **Mean scaling**: Normalize by absolute mean before tokenizing
- **Chronos-Bolt patches**: Chunk history into patches, direct multi-step (250x faster)

### MOIRAI Key Ideas
- **Any-Variate Attention**: Flatten 64 assets → single sequence with variate encoding
- **Multi-patch sizes**: Different patch lengths for different frequencies
- **Student-t mixture output**: Native fat tail modeling (better than Gaussian)
- **Modern tricks**: RoPE embeddings, SwiGLU activation, RMSNorm

### Quick Wins for Poppy
1. **Student-t output** - fat tails without symlog hacks
2. **Variate encoding** - for multi-asset attention
3. **RoPE embeddings** - relative position encoding upgrade

## TASK_116: Student-t Output Distribution - INTEGRATED

Implemented Student-t output distribution for the prediction head, following research from MOIRAI (Salesforce).

### Why Student-t?

Financial returns have heavier tails than Gaussian distributions:
- Standard MSE loss penalizes outliers quadratically → over-fitting to noise
- Student-t NLL: `log(σ) + (ν+1)/2 * log(1 + z²/ν)` where z = (x-μ)/σ
- When ν is small (e.g., 5), outliers are penalized less than MSE
- When ν → ∞, converges to Gaussian (MSE)

### Implementation

**1. Created `mcts_trader/jax_agent/prediction/student_t.py`**:
- `student_t_nll()` - Compute Student-t negative log-likelihood
- `student_t_loss()` - Bounded parameter version with log-space σ and ν
- `StudentTHead` - Flax module to predict uncertainty params from features
- `hybrid_prediction_loss()` - Combines MSE + Student-t with configurable weights
- `maybe_student_t_loss()` - Easy integration wrapper

**2. Integrated into trainer** (`trainer.py`):
- Added `use_student_t`, `student_t_weight`, `mse_weight`, `df_min`, `df_max` to `PredictionLossConfig`
- Modified `_compute_prediction_loss()` with Student-t branch
- Uses adaptive sigma based on error statistics (robust to scale)
- Fixed df from config middle point (df_min + df_max) / 2

**3. CLI Support**:
- `--use-student-t` - Enable Student-t loss for prediction
- `--student-t-weight` - Weight for Student-t NLL (default: 0.8)
- `--student-t-mse-weight` - Weight for MSE component (default: 0.2)
- `--student-t-df-min` - Minimum df (default: 2.1)
- `--student-t-df-max` - Maximum df (default: 100.0)

### Usage

```bash
# Enable Student-t output for training
python train_jax_fast.py --use-prediction-loss --use-student-t

# Adjust fat-tail strength (lower df = fatter tails)
python train_jax_fast.py --use-prediction-loss --use-student-t --student-t-df-min 3.0 --student-t-df-max 30.0
```
