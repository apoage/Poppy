## §151 — Recal verdict: eval-MCTS lifts the BASELINE more than any variant. Campaign scoreboard collapses to zero.

Server agent ran the full eval-MCTS recal sweep on its own initiative (operator pre-approved server-idle autonomy). Tier A/B/C closed 14:23 UTC. **The recal is the result, not 759.**

### The asymmetric-lift finding

759 result.md (yesterday) claimed eval-MCTS sims=16 joint adds +3.66pp to the a1b1 baseline (3 seeds positive). The implicit hypothesis was that this lift would also apply to every variant ckpt evaluated against that baseline — meaning ~3 variants would re-promote (746 oracle, 734 flow, 743 no_aux, 747 td0).

**The recal falsified this hypothesis.** Eval-MCTS lifts the baseline more than it lifts the variants:

| Variant | argmax paired Δα | eval-MCTS paired Δα | Shift |
|---|---:|---:|---:|
| 746 oracle 5-seed | +0.72pp | **−1.20pp** | −1.92pp |
| 734 flow 5-seed | +0.20pp | −0.15pp | −0.35pp |
| 749 Titans b128 3-seed | −3.11pp | −0.33pp | +2.78pp |
| 757 bella_shape 3-seed | −5.80pp | −0.52pp | +5.28pp |

**Net effect: eval-MCTS is a uniform variance reducer, not a uniform lifter.** It rescues regressions toward null and demotes near-wins toward null. STD on 734 collapsed from 6.78pp (argmax variant-only) to 0.98pp (paired) — the s42 −12.71 catastrophe was an argmax artifact, not real seed variance.

### Per-seed mechanism

The recal Tier A1 first 3 cells showed it: a1b1 seeds 31/42 (already-high-α at +6.20/+6.92) **did NOT lift** under eval-MCTS (−0.33/−0.23). Only the lower-Alpha 741 baselines (s7/s13/s23: +7.15/+2.28/−1.04) lifted, and the lift concentrated on s23 (+7.81pp) and s13 (+3.16pp) — the under-performers. s7 didn't move (+0.01pp).

**Eval-MCTS is a ceiling-bounded correction**: it rescues ckpts where argmax decode under-uses the value head's signal in fast-moving regimes. High-α ckpts that already saturate the value head don't move. Low-α ckpts that left value on the table get pulled toward the saturation Alpha (~+6%).

This explains both directions in the recal table — variants that produced high-α ckpts (746, 734) don't ride the baseline lift; variants that produced low-α ckpts (749, 757) get pulled up by the same ceiling effect.
