## Key Technical Decisions

1. **Log-Space Operations**: All price dynamics computed in log-space
   - `next_log_price = log_price + dt * G`
   - Convert back with `exp()` only at output

2. **Low-Rank Correlation**: Factor decomposition `Γ = L @ L.T / k`
   - 8 factors for 64 assets = 512 params (not 4096)
   - Naturally positive semi-definite
   - Captures market factors (sectors, risk factors)

3. **GARCH Volatility**: `σ²_t = ω + α * r²_{t-1} + β * σ²_{t-1}`
   - Models volatility clustering
   - Per-asset parameters for flexibility

4. **Cross-Asset Transformer**: Assets as tokens in self-attention
   - Learns dynamic cross-asset dependencies
   - Complementary to physics correlation

5. **Action Conditioning**: `G_impact` based on action encoding
   - `asset_idx = action // 3`
   - `action_type = action % 3` (sell/hold/buy)

6. **RK2 Solver**: Midpoint method for better accuracy
   - `k1 = f(y_n)`
   - `k2 = f(y_n + dt/2 * k1)`
   - `y_{n+1} = y_n + dt * k2`

## Session 2: Prediction Model Review & CLAUDE.md Rewrite

### Prediction Model Critical Analysis

Reviewed the NeuralOGCM-based prediction model implementation. Key issues identified:

#### Critical Issues Found

| Issue | Severity | Problem |
|-------|----------|---------|
| **Price Representation** | HIGH | Should use log-returns, not raw prices |
| **Action Conditioning Missing** | HIGH | Prediction ignores agent's action |
| **Feature Circularity** | MEDIUM | Features needed during MCTS but env unavailable |
| **Single-Step Training** | MEDIUM | Only 1-step loss, no temporal consistency |
| **Forward Euler Only** | LOW | First-order solver accumulates error |

#### Suggested Mathematical Improvements

1. **Log-Returns (Recommended)**
```python
# Work in log-space
log_returns = log_price[t] - log_price[t-1]
G_phys = alpha * log_returns - beta * (log_price - log_ma) + sigma * noise
next_log_price = log_price + dt * G_phys
next_price = exp(next_log_price)  # Only at output
```

2. **Market Impact Term**
```python
def compute_market_impact(action_history, decay=0.9):
    """Agent's past actions affect prices."""
    weights = decay ** jnp.arange(lookback)[::-1]
    cumulative_pressure = jnp.sum(action_history * weights[:, None], axis=0)
    return cumulative_pressure
```

3. **GARCH Volatility (time-varying)**
```python
# σ²_t = ω + α·r²_{t-1} + β·σ²_{t-1}
next_var = omega + alpha * returns**2 + beta * realized_vol**2
```

4. **Low-Rank Correlation**
```python
# Factor loadings: Γ = L @ L.T / k
# 8 factors for 64 assets = 512 params (not 4096)
```

5. **Multi-Step Prediction Loss**
```python
for t in range(n_steps):
    pred_state = model(state, features[t], noise[t])
    step_loss = mse(pred_state['prices'], trajectory[t+1])
    weight = decay ** t
    total_loss += weight * step_loss
```

#### Priority Order for Improvements

| Priority | Task | Reason |
|----------|------|--------|
| P0 | Fix price representation (log-returns) | Numerical stability |
| P0 | Add `next_prices` to replay buffer | Required for prediction loss |
| P1 | Multi-step prediction loss | Critical for rollout quality |
| P1 | Low-rank correlation matrix | 8x fewer params |
| P2 | Action-conditional dynamics | Model market impact |
| P2 | GARCH volatility | Capture vol clustering |

from mcts_trader.jax_agent.prediction import (
