## TASK_153: Memory-Efficient Buffer Management

**Status:** COMPLETE

### Problem
OOM errors during Easy Mode training due to VRAM spikes:
- Observation size: `(27, 64, 64)` float32 = 432 KB
- Episode (400 steps): 173 MB
- Buffer (32 episodes): 5.5 GB permanent baseline
- Refill spike (32 at once): Additional 5.5 GB temporary
- With `vram_fraction=0.45` on 24GB = 10.8 GB per branch → OOM

### Solution Analysis
Original TASK_153 proposed modifying `_refill_buffer()` to hardcode chunk limit of 4.

**Divergence from plan:** This was unnecessary - `train_easy.py:469` already uses:
```python
n_to_refill = min(self.n_envs, self.N_BUFFER - len(self.buffer))
```

Simply reducing `n_envs` achieves the same goal without code changes to train_easy.py.

### Implementation (e-dojo_v1.py only)

**Refactored to single source of truth:**
```python
class TrainingLauncher:
    DEFAULT_PARAMS = {
        'preset': 'large',
        'epochs': 2500,
        'steps_per_epoch': 400,
        'batch_size': 1024,
        'n_envs': 4,        # Was 32 - limits spike to ~0.7GB
        'buffer_size': 16,  # Was 32 - limits baseline to ~2.8GB
        'vram_fraction': 0.45,
    }
```

**Functions updated to use `**kwargs`:**
- `launch_branch()` - accepts `**kwargs`, merges with `DEFAULT_PARAMS`
- `launch_dual_branches()` - passes `**kwargs` through to branches
- `launch_params` dicts - use `**params` spread instead of repeating fields
- `restart_with_new_levels()` - simplified, uses class defaults

## Security Analysis: Jailbreak Resilience

Analyzed hybrid/latent architecture vs pure LLMs for jailbreak resistance.

**Key Findings:**

1. **Different attack surface** - Discrete action space (12 actions) vs infinite token space. Can't prompt-inject new actions.

2. **Separation of concerns** - LLM generates text but Controller decides actions. Jailbreaking the LLM doesn't control behavior.

3. **Latent space advantage** - Reasoning in vectors, not tokens. Prompt injection doesn't apply to non-linguistic representations. Attacking requires reverse-engineering vector geometry.

4. **Still vulnerable at interface** - Encoder maps English → latent. Adversarial inputs can still find "weak" latent states. Attack surface moved, not eliminated.

5. **Raises the bar** - From "copy-paste prompt" to "researcher with model access." Model-specific attacks don't transfer.

**Conclusion:** Better terrain, not invincible. Invalidates current jailbreak toolkits, requires new research. Security through representation, not rules.
