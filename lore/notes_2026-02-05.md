## Late Session: Weight Merging Research Synthesis

### Research Sources
Executed deep research prompt on 3 independent LLMs:

### Key Finding: The Squisher Shortcut
> **Adam's `v` accumulator approximates diagonal Fisher for FREE** (Li et al., ICML 2025)

```python
# No extra backward passes needed!
fisher_a = opt_state_a[1].nu  # Already computed during training
fisher_b = opt_state_b[1].nu
```

This eliminates the main cost of Fisher-weighted merging.

### Key Finding: Linear Mode Connectivity
> **Same-init branches are linearly mode connected** (Frankle et al., 2020)

Networks sharing initialization converge to solutions connected by LOW-LOSS linear path.
- Git Re-Basin is UNNECESSARY for our setup
- Simple averaging works surprisingly well
- Only need alignment if barrier > 5%

### Research Consensus

| Topic | Gemini | GPT | Claude | **Decision** |
|-------|--------|-----|--------|--------------|
| Fisher cost | High (200 passes) | Extra backward | FREE via Adam v | **Use Adam v** |
| Git Re-Basin | Do it late | Skip | Skip (same init) | **Skip** |
| Optimizer state | Merge momentum | Reset momentum | Average v, Reset m | **Average v, Reset m** |
| Primary metric | Loss barrier | Behavioral | Loss barrier midpoint | **Barrier + Behavioral** |

### Divergence Thresholds (Claude-validated)

| Cosine Sim | Barrier | Action |
|------------|---------|--------|
| > 0.99 | < 1% | Safe. Increase interval 1.5x |
| > 0.95 | < 2% | Normal. FedAvg or Fisher merge |
| < 0.95 | > 2% | Warning. Fisher + distillation |
| < 0.90 | > 5% | **ALERT.** Emergency merge |

### Phase-based Merge Strategy

| Phase | Training % | Method | Interval |
|-------|------------|--------|----------|
| Early | 0-10% | FedAvg | 50-100 steps |
| Mid | 10-70% | Fisher (via Adam v) | 200-500 steps |
| Late | 70-100% | Fisher + TIES | 500-1000 steps |

### Anti-Forgetting Stack
1. **Experience Replay** (primary) - 10% data from other branch
2. **EWC via Adam v** (free) - regularize important weights
3. **Knowledge Distillation** - for policy/value heads

### Optimizer State Post-Merge (CRITICAL)
```python
merged_v = 0.5 * v_a + 0.5 * v_b  # Average second moment (≈ Fisher)
merged_m = zeros_like(m_a)        # RESET first moment (momentum)
# Then: LR warmup for 200-500 steps
```
