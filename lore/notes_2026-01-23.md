## GPU Memory Fix (lax.scan OOM)

### Problem
50 envs × 400 steps × 27×64×64 observations = 4.4GB
- OOM when transferring trajectory batch from GPU to CPU

### Solution
- Don't store observations in lax.scan output
- Store only `window_starts` (80KB instead of 4.4GB)
- Reconstruct observations lazily per-env in CPU loop
- Each env: ~180MB max, processed one at a time

## Dojo V4: Phase 2 Adaptive Difficulty (Major Update)

Rewrote Phase 2 Speed Training to use proper Dojo V2-style adaptive difficulty.

### Multi-Modal Noise Progression

Changed from single `--synthetic-noise` value to `--adaptive-noise` which enables the `AdaptiveNoiseController`. This manages 4 noise types progressively in order:

| Order | Noise Type | Range | Effect |
|-------|------------|-------|--------|
| 1 | Price noise | 0%→100% | Random walk + perturbations |
| 2 | Temporal jitter | 0→5 steps | Observation timing shifts |
| 3 | Time dilation | 0%→30% | Pattern speed variation |
| 4 | Phase shift | 0%→50% | Mid-episode pattern changes |

### Adaptive Triggers

Features enable based on performance thresholds (not fixed stages):

| Feature | Trigger | Behavior |
|---------|---------|----------|
| **Adaptive Noise** | reward > 5 AND rising | Enables `--adaptive-noise`, controller manages all 4 types |
| **Fees** | reward > 5 AND rising (after noise active) | Ramps 0→28 bps (slippage 0→2 bps) |
| **Burning Money** | hold rate > 50% | Enables cash opportunity cost |

### Weighted Level Selection

Phase 2 uses weighted random level selection (not cycling):

| Levels | Category | Weight Share |
|--------|----------|--------------|
| L0-L4 | Easy | ~12% |
| L5-L9 | Medium | ~31% |
| L10-L14 | Hard | ~57% |

### Mandatory Benchmarks

- Benchmark runs after Phase 1 completion
- Benchmark runs after EACH Phase 2 completion (including retries)
- Results saved to `logs/benchmarks/benchmark_results.csv`
- DS24 dashboard reads this CSV for visualization

### Retry Logic

If Phase 2 avg per-epoch reward < 5:
- Retry up to 3 times
- Each retry resets adaptive difficulty state (noise OFF, fees=0)
- Best checkpoint kept even if all retries fail

### DS24 Level 3 Logging

Enabled for prediction head evolution + TRM heatmap:
```
--ds24-level 3
--ds24-intermediates-every 10
```
