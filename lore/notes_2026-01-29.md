# Session Notes: 2026-01-29

## Critical Bug Hunt: TASK_121 & TASK_122 - Future Leakage Fixes

### Context
After training showed 777-1492% alpha on epoch 1 (should be ~0% for random model), launched multi-model adversarial bug hunt using Kimi, Gemini, and Claude. Each model found different bugs due to different reasoning approaches.

### Bugs Fixed

**TASK_121 (Previously Applied):**
1. **Observation Window Forward→Lookback** - Agent was seeing 59 future prices in every observation
2. **Trading Price Offset** - Removed `+window_size` from trading execution (was trading at t+60)
3. **Episode Start Constraint** - Added `min_start = window_size - 1` for lookback room
4. **Optimal Alpha Units** - Scaled by 100 to match agent reward units

**TASK_122 (Fixed Today):**
1. **Infinite Overfitting Loop** (Gemini) - Environment states never reset between epochs. Agent memorized same episode thousands of times. Fixed: Added `jit_batch_reset()` after each `run_self_play_jax`.
2. **Differential Reward Future Leak** (Kimi) - Was using `prices[1:]` (future) for market baseline. Fixed: Changed prepend→append for concurrent return.
3. **Encoder Return Denominator** (Kimi) - Formula was `(p[t]-p[t-1])/p[t]` instead of `/p[t-1]`. Fixed in both `jax_encoder.py` and `state_fast.py`.
4. **Episode Start Range** (Kimi) - Edge case where only 1 valid start position. Fixed: `min_start + 10`.

### Files Modified
- `train_jax_fast.py`: Added `jit_batch_reset` import; reset env states after self-play; fixed differential reward timing
- `mcts_trader/env/jax_trading_env.py`: Episode start range edge case
- `mcts_trader/env/jax_encoder.py`: Return denominator fix

### Remaining Concern: Instant Execution
Even with all bugs fixed, synthetic data may show high alpha due to simulation design:
- Agent observes Close[t] and executes at Price[t] (zero latency)
- On sine waves, this allows perfect timing
- Not a bug, but a realism limitation
- Consider: shift execution to t+1 for more realistic simulation

- **Claude**: Integration and fixes
- Expensive but catches bugs single-model would miss
