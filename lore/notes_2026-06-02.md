### C0 KILLed — but we caught ourselves testing the wrong thing
The token viability gate came back **KILL** (real-vs-shuffled edge +0.0003 vs a +0.01 bar). For a few
minutes that read as "tokens are dead." Then the operator called it — *that 893-second run could not
have tested the idea.* Reading the harness confirmed it: C0 aggregated to **hourly** (we trade
minutes), tested a **5-asset toy**, and — fatally — judged the vocabulary by a **next-bar-sign probe**,
the one thing this design explicitly does **not** do. It killed a strawman, not the mechanism. **KILL
withdrawn as decisive.** A good lesson, twin to the C0 sign-probe being the same error class as the 14
dead classifier tweaks: *measuring the wrong thing produces confident, worthless verdicts.*

### The reframe that followed — a language of shapes, corrected three times
What the operator actually wants, after three corrections to my misunderstanding:
- **Minute** granularity (not hourly).
- **Non-predictive.** The tokenizer builds a *vocabulary* of recurring candle shapes; it never
  forecasts. "Meaning" is learned later, downstream, never as a forecast.
- **Single-asset, adaptive.** Transfer across the 64 assets is a **property of the encoding** (vol-unit
  relative moves + one shared codebook), not learned cross-asset attention.
- **F1 = vol-unit magnitude.** A move is measured in local-volatility units, so a big and a small
  version of the same proportional shape are *different* tokens (magnitude is identity); the $225/unit
  and $0.45/unit versions still collapse to the same token because a rescale leaves vol-units unchanged.

Pipeline: ① tokenizer (the language) → ② masked-token embedding (contextual meaning, non-predictive) →
③ the existing trader on tokens (compressed, denoised). And the operator's two structural ideas that
made it sing: **a PANEL of isolated languages** (L1 BPE-delta, L2 ABBA, L3 SAX-grammar, L4 learned
VQ/FSQ, L5 Matrix-Profile) over one shared substrate, each *seeing different structure* — and **one
multilingual model** that speaks all of them in a shared embedding space, the way an LLM speaks many
human languages. The kicker: our languages are **perfectly parallel re-encodings of the same bars**, so
cross-language alignment has free supervision — the shared time axis *is* the parallel corpus.

### Judging a language without a predictor
The eval battery that replaces the sign-probe judges a vocabulary like a *language/codebook*, not a
forecaster: **A8 cross-asset transfer** (the headline — beat both a returns-shuffle AND a random-merge
same-size vocab, mega-tokens excluded), corrected **A1 MDL** (charge null + boundary bits), **A2**
reconstruction, **A9** length non-degeneracy. The adversarial pass caught the obvious "real vs
time-shuffle" control as **circular** (any tokenizer beats its own shuffle on autocorrelated minute
data) — same trap as the sign-probe, demoted to a control input only.

### Built like an engineer, audited like a pessimist
The operator wants it **JAX-native, GPU, max parallelism** — and the single-asset property is the gift:
`(asset, window)` is an embarrassingly-parallel **flat sample axis**, so 64 is not a ceiling. Two hard
constraints: **stream DB → bounded RAM ring → VRAM** (never full-load), and **OOM/leak safety is
paramount** (shared training server; a leak is an incident). Two workflows did the work: a 5-lens
research pass (→ `docs/candle_language/`, the full design + critique + findings) and a build-scope pass
(repo maps → build plan → adversarial leak/OOM audit). **The audit earned its keep:** it caught a
*server-incident-class* hazard the plan was blind to — a blind `--gpu 1,2,3` pmap at `mem_fraction=0.7`
would grab 0.7 of *each* GPU at init and collide with the standing 2-wide-train + GPU-3-eval contract,
OOM-ing the co-tenant (safe_run's cgroup is RAM-only; **no VRAM envelope exists**). Corrected posture:
**single-GPU on a verified-idle GPU**, multi-GPU only when the pool is confirmed empty. Plus a real FSQ
`bound()` bug (even levels → only 7/8 codes reachable) and an eval-path full-load in disguise. Six
blocking corrections, all in `TASK_795`.
