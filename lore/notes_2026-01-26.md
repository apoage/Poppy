## TASK_116: Student-t Output Distribution - INTEGRATED

Implemented Student-t output distribution for the prediction head while CNN diffusion training runs.

### Why Student-t?

Financial returns have heavier tails than Gaussian:
- MSE penalizes outliers quadratically (over-fits to noise)
- Student-t NLL: `log(σ) + (ν+1)/2 * log(1 + z²/ν)`
- Small ν (e.g., 5) = fat tails, outliers penalized less
- Large ν → Gaussian behavior

### Design Decisions

1. **Adaptive sigma**: Uses `std(errors)` per-step - no learnable params needed
2. **Hybrid loss**: 80% Student-t + 20% MSE (stability)
3. **Fixed df**: Midpoint of [df_min, df_max] range
4. **No architecture changes**: Works with existing prediction head

## TASK_118: Alpha-Relative Reward - COMPLETED

**Idea:** Reward based on `achieved / max_possible_alpha` instead of raw PnL.

**Problem:** Computing max_possible_alpha for 64 assets is NP-hard.

**Solution:** Top-k selection per timestep. Don't need optimal route, just the sum!

```python
# O(T × n), 0.093ms per call
max_alpha = jnp.sum(jax.lax.top_k(jnp.abs(returns), k=4)[0])
```

```python

    # Track when top-k membership changes between steps
```

### Bug Fixed During Implementation

Sinkhorn implementation had numerical instability (NaN from overflow):
- **Cause:** `-C/eps` reached ~50, `exp(50) = 5e21` overflowed Sinkhorn iterations
- **Fix:** Log-domain Sinkhorn with `logsumexp` + score normalization + clip

### API Usage
