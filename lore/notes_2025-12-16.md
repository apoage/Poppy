### Resolved Issues

#### NaN Loss (2025-12-09)

#### Paper Trading Bugs (2025-12-11)
- Unit confusion and position sizing bugs addressed

#### FX Rate Fallback / "Turtle" Collapse (2025-12-16)
1. **Database:** Created `fx_rates` table (`tools/build_fx_database.py`) with ~860k records using Weighted Consensus from crypto bridges
2. **Validation:** Verified against Kraken Ticker (`tools/validate_fx_rates.py`) with ~0.24% deviation
3. **Integration:** `HistoricalMarket` preloads `fx_rates` into RAM. `FastTradingEnv` fetches authoritative rates
4. **Verification:** Smoke test (50 steps) confirmed smooth execution

#### DS24 Metrics Logging (2025-12-31)
1. **MCTS Metrics:** Added `mcts_root_values` tracking in `run_self_play` and `run_self_play_batched`
2. **Planning Logging:** Integrated `ds24_logger.log_planning_metrics` in `train_jax_fast.py`
3. **Physics Logging:** Integrated `ds24_logger.log_physics_components` when `--use-prediction-loss` active

### Training Controls Added
