## Session 19 — TASK_699 Implementation & Deployment

### TASK_699 Draft v1 → v2 (Bug Hunt)

Reviewed the implementation draft for batched AR rollout speedup. Found **9 bugs** (3 critical, 2 medium, 4 low/minor) in the original pseudocode. All fixed in v2 of `tasks/TASK_699_imp_draft.md`.

#### Critical Bugs Fixed

1. **JIT recompilation on variable B** — AR episode count per refill is Binomial(4, 0.89), so B varies between 2-4. Each new B value triggers full JIT retrace (10-60s). Fix: pad to fixed `B=n_envs` (static_argname), discard padding results.

2. **capacity sums wrong axes** — `jnp.sum(jnp.abs(pos) > 0.5) / k` flattens both B and n_assets into one scalar shared across all episodes. Fix: `axis=-1, keepdims=True` → `(B, 1)`, then `broadcast_to`.

3. **jnp.stack axis wrong** — `jnp.stack([pos, pnl, ...])` with `(B, n_assets)` arrays gives `(6, B, n_assets)` not `(B, 6, n_assets)`. Fix: `axis=1`.

#### Medium Bugs Fixed

4. **scan output shape** — `jax.lax.scan` stacks outputs along new leading axis → `(T, B, 6, n_assets)` not `(B, T, 6, n_assets)`. Fix: `jnp.transpose` after scan.

5. **All tile/concat axes** — every `jnp.tile` and `jnp.concatenate` needs axis shifts for the batch dim. Complete shape trace added to draft.

#### Low/Minor Fixes

6. **bf16 Option A is a no-op** — TRM encoder immediately does `x.astype(self.dtype)` where `dtype=float32`, undoing the bf16 cast. Skip Option A entirely; Option B deferred to follow-up.

7. **Ragged returns assertion** — all episodes have same length in practice (same config). Added assert to fail fast if not.

8. **`i in list` → `set()`** — O(n) lookup replaced with O(1).

9. **`unroll=2` not `unroll=4`** — scan body contains full 50M param forward pass. `unroll=4` quadruples XLA code size. Start conservative with `unroll=2`.

### Edge Case Verification (Post-Implementation Review)

- ar_episode_set empty (ar_blend=0 or all flips miss): batched path skipped, oracle state used
- All episodes AR (B_actual = n_batch ≤ n_envs): padding fills gap, results distributed correctly
- B_actual < B_pad: padding episodes get zeros, model runs on zeros (no NaN), results discarded
- n_batch < n_envs: B_pad = n_envs still works (more padding)
- Single-episode path (line 723): still uses unbatched `self._model_state_rollout`, untouched

No new bugs introduced.
