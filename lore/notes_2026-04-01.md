### TASK_716c: Dynamics Loss + Training Loop (Stage A core)

Implemented full Stage A dynamics training in `train_phase2.py`:

**Components added**:
- `scalar_to_categorical()` — standalone function matching EasyTrainer._scalar_to_target for JIT
- `_is_dynamics_key()` — helper for param path filtering
- `make_dynamics_mask()` — boolean mask: True for dynamics, False for frozen params
- `create_dynamics_optimizer()` — optax.masked(adamw + warmup_cosine, dynamics_only)
- `make_dynamics_train_step()` — JIT-compiled train step with closure over model+optimizer:
  - Encodes obs_t, obs_t1 through frozen encoder (stop_gradient)
  - Runs recurrent_inference for dynamics prediction
  - Consistency loss: MSE(pred_latent - target_latent)
  - Reward loss: categorical CE with scaled per-step rewards (REWARD_SCALE=100)
  - Metrics: consistency, reward, total, grad_norm, pred/target latent_std
- `ConsecutivePairGenerator` — samples consecutive cursor pairs from SegmentPool:
  - Validates cursor+1 is in bounds for both prices and returns
  - Encodes both price windows via jit_batch_encode_temporal
  - Extracts oracle actions (argmax of policy_targets), per-step rewards
  - Optional state channel support
- `save_checkpoint()` — pickle with params, config, epoch, metrics, phase, stage
- `train_stage_a()` — full training loop with per-epoch logging, best tracking, periodic saves
