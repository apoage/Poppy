## Bug 3 Fixed: Same-Step Observation Leak

### The Problem
Agent observed `prices[t]` before deciding to execute at `prices[t]` - classic look-ahead bias.

```python
# OLD formula (buggy):
start_idx = episode_start + current_step - window_size + 1
# Window covered: [t-59, t] → agent sees prices[t] before trading at it!

# NEW formula (fixed):
start_idx = episode_start + current_step - window_size
# Window covers: [t-60, t-1] → agent only sees up to prices[t-1]
```

### Files Modified
- `jax_trading_env.py`:
  - Line 1306: `compute_observation_27ch()` - removed `+ 1`
  - Line 1331: `compute_observation_31ch()` - removed `+ 1`
  - Line 1357: `compute_observation()` - removed `+ 1`
  - Line 1065: `reset()` - `min_start = window_size` (was `window_size - 1`)

### Why This Caused Massive Alpha
On synthetic L0 sine waves, knowing `Close[t]` perfectly identifies current momentum. Even a random model with lucky weights on return features (e.g., positive weight on `prices[t] - prices[t-1]`) will buy on uptrends and sell on downtrends, capturing the entire wave.

## Bug 5 Fixed: Limit Order Short Opening - FREE MONEY BUG

### Root Cause
When opening SHORT positions via limit sell orders, **NO MARGIN WAS DEDUCTED**!

**File:** `mcts_trader/env/jax_trading_env.py:615` (in `fill_limit_orders`)
```python
# OLD (buggy):
cash_change_sell_short = jnp.where(opening_short, 0.0, 0.0)  # Short doesn't change cash immediately
```

This was a **FREE MONEY** exploit:
1. Agent places limit sell order (lazy mode - no cash reserved)
2. Order fills → SHORT position created
3. Position valued at `size * entry_price`
4. **BUT NO CASH DEDUCTED!**
5. Portfolio value increases by position value for FREE

### Fix Applied
```python
# NEW (fixed):
# Calculate short margin (same as market order)
short_margin_cost = state.order_size * sell_fill_price
short_margin_fee = short_margin_cost * maker_fee_rate
total_short_margin = short_margin_cost + short_margin_fee

# Check affordability
can_afford_short = total_short_margin <= available_for_short
opening_short = wants_to_open_short & can_afford_short

# DEDUCT MARGIN
cash_change_sell_short = jnp.where(opening_short, -total_short_margin, 0.0)
```

### Impact
**Before fix:** Random model on L0 synthetic showed ~76% average alpha
**After fix:** Random model shows ~-1% alpha (expected due to fees/slippage)

## TASK_125 Created: Causal Expert Imprinting

### Problem
AMAX (TASK_119) leaks future by design - computes hindsight-optimal path using future returns and trains policy toward it. Even with bugs fixed, this teaches "patterns" that require future knowledge.

### Solution: Retrospective Expert Buffer
Key insight: **temporal separation**

```
Episode N runs    → Agent trades normally (NO expert loss)
Episode N ends    → Compute optimal path (hindsight NOW valid)
Episode N+1 train → BC loss from episodes 0..N (causally valid!)
```

### Components Designed
1. **ExpertBuffer** - stores (obs, optimal_action) from COMPLETED past episodes
2. **BC Loss** - behavioral cloning toward historical optimal
3. **Pattern Mining** - extract recurring profitable setups (optional)
4. **HER Relabeling** - relabel failed trades with achieved goals (optional)

### Research Areas
- DAgger, GAIL for mixing RL + BC
- HER (Hindsight Experience Replay) for goal relabeling
- BC weight scheduling (high early, decay late)
- Distribution shift handling

### Files Created
- `tasks/TASK_125_CAUSAL_EXPERT_IMPRINTING.md` - full design doc with research prompt

### Research Documents Added
- `docs/imprinting/Causal Expert Imprinting.txt` - comprehensive theoretical framework
- `docs/imprinting/compass_artifact_*.md` - practical implementation guidance

### Key Research Findings
1. **Q-Filter** for BC weight: Apply BC loss ONLY when `Q(demo) > Q(policy)` - automatically decays
2. **Dual Buffer Architecture**: Demo buffer (10⁴-10⁵) + Agent buffer (10⁵-10⁶)
3. **HER k=4-8**: Relabel failed trades with achieved returns as goals
4. **Regime-aware sampling**: 3x boost for matching regime, 20% cross-regime
5. **Causal TCN**: LEFT-PAD ONLY to ensure output[t] depends on inputs ≤t
6. **LUPI framework**: Expert has privileged X* (future), student learns causal features from X
7. **DQfD loss**: Large margin classification forces Q(expert) > Q(other) + margin
