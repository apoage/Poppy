## TASK_125: Causal Expert Imprinting - Phase 2 Complete

### What Was Done

1. **Implemented BC Loss with Q-Filter** (trainer.py)
   - Cross-entropy loss toward optimal actions from completed episodes
   - Q-filter: Only apply BC when Q(demo) > Q(policy) - auto-decays as agent improves
   - Large margin option (DQfD-style)
   - Weight decay: 0.1 → 0.01 over 50k steps

2. **Added CLI Flags** (cli.py, config.py)
   - `--imprint` - Enable causal expert imprinting
   - `--bc-weight-initial/final` - BC loss weight control
   - `--bc-weight-decay-steps` - Decay schedule
   - `--expert-demo-capacity` - Max demos to store
   - `--expert-confidence-threshold` - Min alpha capture to store

3. **Episode Completion Callback** (train_jax_fast.py)
   - Stores demos from positive-alpha episodes
   - Computes optimal path using path_solver
   - Stores ALL steps (~100-400 per episode) with confidence weighting

4. **Fast Observation Sampling** (expert_buffer.py)
   - Initial approach: Full JAX encoder reconstruction - TOO SLOW (4s per batch)
   - Final approach: Simplified raw price features - FAST (<0.1s per batch)
   - Trade-off: Less accurate observations, but functional for testing

## Phase 1 Critical Fixes (COMPLETED)

### BUG-001: BC Confidence Masking
- **File**: `trainer.py:1418-1427, 1434-1443`
- **Fix**: Changed from simple mean to masked mean
- Before: `jnp.mean(loss * confidence)` dilutes with zeros
- After: `jnp.sum(loss * confidence) / jnp.sum(confidence)`

### BUG-002: PER Importance Weights
- **File**: `trainer.py:1385-1427`
- **Fix**: Apply `per_weights` from expert_buffer to BC loss
- Combined with confidence: `loss * confidence * per_weights`

### BUG-003/004: PopArt Weight Correction
- **File**: `trainer.py:1616-1642`
- **Fix**: DISABLED weight correction (incompatible with categorical heads)
- Kept: Normalization (valid), Removed: Weight scaling (broken)

### BUG-005: MCTS Visit Count Normalization
- **File**: `self_play.py:219-226`
- **Fix**: Defensive normalization before storing policy targets
- `policy_array = policy_array / np.sum(policy_array)`

### BUG-006: MuZero Consistency Loss
- **File**: `trainer.py:1115-1145`
- **Fix**: Added `consistency_loss = ||predicted_latent - stop_gradient(true_latent)||²`
- Prevents dynamics model drift during unrolling
- Weight: 0.5 (configurable)

## Phase 2 High Severity Fixes (COMPLETED)

### BUG-007: Demo/Agent Priority Scale Mismatch
- **File**: `expert_buffer.py:161, 518-522, 578`
- **Fix**: Scale demo priority by `confidence * max_priority + boost` to be competitive with agent TD-errors (~1-10)
- Before: `confidence + boost` (~0.9) << agent priorities
- After: `confidence * max_priority + boost` (scales to agent range)

### BUG-009: Demo Zone Sampling (Stratified)
- **File**: `expert_buffer.py:487-525`
- **Fix**: Replace `np.random.choice` with stratified sampling (like segment tree)
- Divides total priority into n segments, samples one from each segment
- Ensures coverage across all priority levels

### BUG-010: Main Replay Buffer Sampling
- **File**: `replay_buffer.py:255-278`
- **Fix**: Mixed recent/uniform sampling (50/50) instead of recent-only
- Before: Only sampled from most recent ~0.2% (heuristic_window)
- After: 50% recent + 50% uniform from full history
- Prevents catastrophic forgetting of old strategies

### BUG-011: Enable Weight Decay Config
- **Files**: `config.py:151`, `cli.py:111-112`, `setup.py:497`
- **Fix**: Added `weight_decay` config option (default 1e-4)
- Properly passed through to trainer's AdamW optimizer

### BUG-013: Reduce Global Gradient Clip
- **Files**: `config.py:152`, `cli.py:113-114`, `trainer.py:406, 557`
- **Fix**: Reduced from hardcoded 10.0 to configurable 5.0 (default)
- Added `global_grad_clip` config option

### BUG-015: Remove Unused Target Network
- **File**: `trainer.py:249-251, 385, 513, 594-596, 1557-1567`
- **Fix**: Removed dead code - target_params was defined, initialized, and updated every 100 steps but NEVER used anywhere
- MuZero uses MCTS returns for value targets, not TD bootstrapping
- Saves memory (duplicate params) and compute (update logic)

### BUG-017: Add Gradient Blocking (stop_gradient)
- **File**: `muzero_model.py:235-243`
- **Fix**: Added `jax.lax.stop_gradient(next_latent_state)` before prediction
- Standard MuZero blocks gradients from value/policy heads to dynamics/encoder
- Prevents encoder from being corrupted by dynamics gradients

### BUG-035: Burn Sign Error in Bearish Markets
- **File**: `jax_trading_env.py:1226`
- **Fix**: Clamp `market_burn` to non-negative with `jnp.maximum(..., 0.0)`
- Before: Negative market_return led to negative burn which became a reward via symlog
- After: In bear market, holding cash has no opportunity cost (correct behavior)
