### Part 2: Extract Magic Numbers into PhysicsConfig

Created `PhysicsConfig` dataclass to make hardcoded values configurable:

| Parameter | Default | Description |
|-----------|---------|-------------|
| `reward_scale` | 100.0 | Scale for categorical bins |
| `alpha_target` | 0.05 | Momentum regularization target |
| `beta_target` | 0.03 | Mean reversion target |
| `sigma_target` | 0.01 | Volatility target (use 0.03 for crypto) |
| `label_smoothing` | 0.1 | Categorical distribution smoothing |
| `min_entropy` | 3.0 | Policy collapse threshold |
| `max_positions` | 16 | Max simultaneous positions |
| `min_cash_threshold` | 100.0 | Min cash to allow buying |
| `confidence_threshold` | 0.0 | Force HOLD if max_prob below |

**New CLI flags:**
```bash
--reward-scale, --alpha-target, --beta-target, --sigma-target
--label-smoothing, --min-entropy, --max-positions
--min-cash-threshold, --confidence-threshold
```
