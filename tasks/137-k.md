# TASK_137: Investigation: -102% Alpha with Agent Continuation

**Status:** INVESTIGATION COMPLETE - NOT A BUG (Expected Behavior)
**Date:** 2026-02-01

## Summary

**Finding:** -102% alpha is mathematically possible and NOT an error. The liquidation system is working correctly.

**Why:** Alpha = Agent Return - Market Return. If agent loses everything (-99%) while market gains (+3%), alpha = -102%.

---

## Investigation Results

### 1. Liquidation Logic EXISTS and is Working

Found in `mcts_trader/env/jax_trading_env.py`:


**Liquidation triggers at -99% portfolio value** (when $100k drops to $1k).

### 2. Margin Call / Bankruptcy Protection EXISTS

```python
# Lines 325-400: process_margin_call function
# - If cash < 0: Liquidate long positions to cover
# - If still negative: Bankruptcy (wipe everything, cash = 0)
# - Portfolio value floor at $0 (cannot go negative)
```

**Portfolio value cannot go below $0** due to bankruptcy protection.

### 3. The -102% Alpha Mystery SOLVED

Alpha calculation (from `self_play.py:851`):
```python
alpha = final_return - market_return
```

**Scenario that produces -102% alpha:**
```
Agent portfolio: $100,000 → $1,000 (liquidated)
Agent return: (1000/100000 - 1) × 100 = -99%

Market (buy & hold): +3% over same period

Alpha = -99% - (+3%) = -102%
```

**This is mathematically correct!** Alpha is not bounded by -100%.

### 4. Why Agent Appears to "Continue Trading"

**The agent does NOT continue trading after liquidation.**

What happens:
1. Portfolio hits $1,000 liquidation threshold
2. `is_liquidated = True`
3. `done = True` (episode ends)
4. Episode reports final alpha (e.g., -102%)
5. **New episode starts** with fresh $100,000

The CSV/log shows "-102% alpha" from the **completed** episode, not an ongoing one.

## Burning Money Edge Case Analysis

The "burning money" feature (TASK_051) can cause portfolio to go below liquidation threshold:

```python
# Lines 1244-1271: Random burn after liquidation check

    actual_burn = jnp.where(should_burn, jnp.minimum(burn_amount, new_state.cash), 0.0)

```

**Impact:** If burning_money is enabled, portfolio can briefly go below $1,000, but:
1. Episode still ends (`done` was already computed)
2. Bankruptcy protection prevents negative cash
3. Worst case: portfolio = $0, return = -100%

With -100% agent return and +3% market return: **alpha = -103%** (still valid)
