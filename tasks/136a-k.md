## 2. MEMORY ANALYSIS

### 2.1 Full Observation Storage (Infeasible)

```
Per observation: (27 channels, 64 assets, 64 assets) × 4 bytes
= 27 × 64 × 64 × 4 = 442,368 bytes = 442 KB

50k demos × 442 KB = 22.1 GB
```

**Verdict:** ❌ Exceeds typical RAM (32-64 GB systems)

### 2.2 Compressed Storage - KEY INSIGHT ✅

**Critical observation:** The encoder output is **heavily redundant**:

```python
# From jax_encoder.py:_compute_all_channels()
# EVERY channel uses jnp.tile to create (n, n) from (n,) or (n, 1):

output = output.at[0].set(jnp.tile(norm_prices[:, -1:], (1, n)))  # Close
output = output.at[4].set(jnp.tile(returns_1m[:, -1:], (1, n)))   # 1m return
output = output.at[5].set(jnp.tile(returns_5m[:, None], (1, n)))  # 5m return
# ... ALL 27 channels follow this pattern
```

**Key insight:** Each channel is a **row-wise tile** of a 1D vector:
- Channel shape: (64, 64) where every row is identical
- Storage: (64,) per channel instead of (64, 64)
- Compression ratio: 64×

**Compressed size:**
```
Per observation: (27 channels, 64 assets) × 4 bytes
= 27 × 64 × 4 = 6,912 bytes = 6.75 KB

50k demos × 6.75 KB = 338 MB ✅
```

**Verdict:** ✅ Easily fits in RAM

### 2.3 Memory Summary Table

| Component | Current | With Pre-encoding | Delta |

| Index storage | 27 MB | 27 MB | - |
| Episode prices | 25 MB | 0 MB (not needed) | -25 MB |
| Encoded observations | 0 MB | 338 MB | +338 MB |
| **Total** | **52 MB** | **365 MB** | **+313 MB** |

#### Change 3: jax_encoder.py - Add compression helper (optional)

```python
def compress_observation(obs: jnp.ndarray) -> jnp.ndarray:
    """Compress (27, n, n) to (27, n) by taking first column.
    
    All channels are row-wise tiles, so first column represents all data.
    """
    return obs[:, :, 0]  # (27, n)

decompress_observation(compressed: jnp.ndarray) -> jnp.ndarray:
    """Decompress (27, n) back to (27, n, n) by tiling."""
    n = compressed.shape[1]
    return jnp.tile(compressed[..., None], (1, 1, n))  # (27, n, n)
```
